# Personal Portfolio Website

Source code for my personal portfolio website showcasing my work as a Senior Flutter Developer & Mobile Engineer.

## Live Website
Visit: [santosh-adhikari.com.np](https://santosh-adhikari.com.np)

## About
Personal portfolio featuring:
- Hero section with stats and CTA
- Bento-grid About section
- Animated skill bars
- Experience & Education timelines
- Project showcase with hover overlays
- Contact form (Formspree)
- Fully responsive — mobile, tablet, desktop

## Built With
- HTML5
- CSS3 (custom properties, CSS Grid, no frameworks)
- Vanilla JavaScript (no jQuery)
- [Inter](https://fonts.google.com/specimen/Inter) — Google Fonts
- [Formspree](https://formspree.io) — contact form backend

## Hosting
- GitHub Pages
- Cloudflare (CDN + DNS)

## Contact Form Setup
The contact form uses Formspree. To activate it:
1. Sign up at [formspree.io](https://formspree.io)
2. Create a new form
3. Replace `YOUR_FORM_ID` in `index.html` with your form's ID

Until configured, the form falls back to a `mailto:` link.

## Local Development
```bash
git clone https://github.com/cntoss/portfolio.git
cd portfolio
# Open index.html directly in your browser — no build step needed
```
